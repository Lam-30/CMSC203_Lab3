# CMSC203_Lab3
Lab 3 - Create Driver for DataElement
Course: CMSC203

Description 
This lab demonstrates how to create a Java driver class to test a separate data element class.

Lab Objectives
  - Create and test a java class
  - Create objects using constructors
  - Use setter and getter methods
  - Read user input using Scanner
  - Use a loop to enter information for multiple movies

Files Included
  - Movie.java : Contains movie information, constructors, getters, setters, and the toString     method.
  - MovieDriver.java : Driver program that allows users to enter movie information and displays the results

How to Run
1. Open the project Eclipse.
2. Run MovieDriver.java.
3. Enter the movie title, and number of tickets sold.
4. Choose whether to enter another movie.
